# 英译中补充规则

## 执行与规则优先级

- 书籍依 [TRANSLATION_WORKFLOW.md](TRANSLATION_WORKFLOW.md)，单篇文章依 [ARTICLE_TRANSLATION_WORKFLOW.md](ARTICLE_TRANSLATION_WORKFLOW.md)。角色权限、工件、盲审隔离和停止条件保持不变。
- 翻译依 [TRANSLATION_STYLE.md](TRANSLATION_STYLE.md)，审校依 [REVIEW_STYLE.md](REVIEW_STYLE.md)。其中关于俄语句法、词形和原文的语言专属要求，在当前任务中按英文底本与以下规则执行。
- 中文标点、文献责任、注释对应及样式依 [PUNCTUATION.md](PUNCTUATION.md)；英文特有形式按以下规则判断，不逐字符转换。
- 书籍中的文章或章节不因具有独立标题而自动适用单篇文章的正文删减、摘要、引言和参考文献结构规范化规则。

## Operator

- 从选定英文底本直接译成中文。底本中的作者论述、引文、原文译者说明和编者说明分别保持其身份。
- 英文底本本身为其他语言的译本时，以选定英文版本为本次翻译依据；俄文或其他版本只辅助核对，不静默改换底本、补回删节或替换英文译者的处理。版本差异按原文疑点交接。
- 准确性优先于语言自然度，语言自然度优先于术语一致性。保留概念区别、论证顺序、限定、否定、指代、情态和有意义的重复。
- 使用自然、清楚的现代汉语。按实际语义处理冠词、单复数、时态、被动结构、名词化和长定语，不机械逐词对应；重组句法不得改变施动关系、范围、时间关系或确定程度。
- 按语境区分 `may`、`might`、`must`、`should` 等词所表达的可能、推断、义务或规范含义，不统一译成同一种语气。
- `ideal`、`material`、`activity`、`subject` 等多义词按概念、句法及语境判断，不因英文词形相同强制采用同一中文译法。
- 引文翻译作者实际引用的英文，保留其省略、强调、改写和版本信息；不以俄文原作、其他英文版本或通行中译替换。
- 保持自然段、结构元素与注释对应；已有 block-id 时，编号、顺序和数量不变，不跨 block 合并、拆分或移动正文。
- 术语使用相关全局词条；真实不确定性、权威冲突和底本疑点按对应流程交接，不自行建立新的长期译法权威。

## Reviewer

- 对照选定英文底本判断译文是否需要修改，依次检查准确性、语言自然度和术语一致性。
- 检查漏译、增译、概念混淆，以及主客体、施动关系、指代、否定、限定范围、程度和情态变化；特别检查中文句法重组是否改变论证关系。
- 区分英语名词化、被动句和嵌套从句中的实际关系，修正影响理解的直译，不以个人文风偏好重写准确、成立的中文。
- 英文译本与其他语言文本不同，不直接判为本次中文翻译错误；先区分版本差异、英文底本问题与中文误译，再按对应流程处理。
- 按概念和语境核对全局 `approved` 的 `zh_preferred`；词形相同、候选译法或英文异名不能单独作为判错依据。
- 检查英文题名、大小写、斜体、缩写及文献责任向中文转换是否正确，注释与引证是否保持原有身份和对应关系。
- 修改分类及记录按对应流程执行；书籍审校使用流程规定的 reports 和 `rv:`，单篇文章不建立这些书籍工件。明审不直接修改译文，Finalization 不重新进行全文审校。

## 题名、标点与样式

| 英文形式或功能 | 中文处理 |
| --- | --- |
| 单引号或双引号中的普通引文、反语、特殊用语 | 外层用 `“……”`，内层用 `‘……’` |
| 书名、刊名及正式篇章题名 | 按题名身份使用 `《……》`，书名号内嵌题名用 `〈……〉` |
| 独立标题、目录条目 | 不为标题本身额外添加书名号；其中嵌入的作品名照常处理 |
| 插入、解释、中断用的 em dash 或 en dash | 按中文句法使用 `——`、逗号或括号 |
| 年份、页码等范围 | 使用连接号 `—` |
| 英语构词连字符 | 按词义翻译，不机械保留；外文原词内部保留其拼写 |
| 正文省略号 | `……` |
| 引文或底本删节 | `[…]`，不与正文省略号、编者补字混用 |
| 表示题名的斜体 | 转为书名号；独立的强调仍按其原有范围保留 |
| 表示强调的斜体、粗体或全大写 | 按共用标点规范转换，不因英语标题式大小写或缩写而添加粗体 |

- 英文引号与句末标点的位置不直接照搬；按引文是否完整成句及标点责任使用中文形式。
- 保留外文原词、公式及未翻译著录内容内部的拼写、变音符号、标点和必要空格。
- 数字编号、罗马数字、字母分项和正文回指保持对应；英文 `(a)`、`(b)` 等分项在中文中写作 `（a）`、`（b）`，不重新编号。
- 作者—年份制与数字编号制保持原有体系。书籍参考文献按底本及作品规则处理，不自动改换为中文版本书目；单篇文章依共用角色规范处理。

## 姓名与机构

- 姓名保持底本给出的信息粒度：全名译全名，缩写保留缩写粒度，仅有姓氏时不补名字。
- 优先依据已确认身份及全局词条确定中文译名；不能仅凭英语转写反推俄文姓名或把不同人物合并。
- 完整姓名及对应中译能够确认时，缩写按共用标点规范转为中文姓名首字；无法确认时保留英文原缩写，不猜补全名。
- 机构正式名称、机构类别、职务和学科单位分别判断，不把 `department`、`chair` 等词机械等同于单一建制。
- 已有通行中文简称且身份明确时可用简称；否则按已确认全称译出，不根据歧义缩写猜定机构。原文明确的历史限定、隶属关系与命名者信息应保留。

## 文献责任与注释

- `Ed.`、`Eds.`、`Compiler`、`Author` 和 `Trans.` 按所在版本及明确署名判断责任，不把英文译本的译者说明记为本次中译者说明。
- 英文底本中既有译者的说明标为“原文译者”；书籍编者、编纂者、作者、原刊编者和来源网站编者分别保留其身份。已有姓名或缩写署名继续译出，不改成笼统责任标签。
- 方括号可能表示补字、删节、引证或编者说明，须按内容与版本约定判断，不统一转换为 `〔……〕`。
- 原版页码标记按共用规范处理，不据此改写索引页码、脚注 ID 或参考文献编号。
- 不擅自添加本次中译者注。Owner 明确授权后，依共用规范使用译者短注或 `[^zh-N]` 长注，并保持标记与定义完整对应。
- 书籍脚注保留既有作用域 ID；单篇文章注码、例外裁决及显示注码标记依共用规范执行。

## 术语权威与维护

- 中文术语统一使用任务指定的术语目录，归属、状态和维护权限依 [GLOSSARY_RULES.md](../glossary/GLOSSARY_RULES.md)，不另建作品或丛书的中文权威表。
- 专名和体制词、通用学科术语、作者理论概念分别归入既有对应文件；文集按概念所属作者判断，不以编者代替概念作者。
- 只有 `approved` 的 `zh_preferred` 是既定中文权威。`forms` 中的英文只辅助识别实体或概念，不表示所有同形英文均对应该词条。
- `provisional` 只是候选，既有 `needs_review` 只读参考；不因本规则启用而改变任何条目的批准状态。
- Operator 的新增或修改建议进入 handoff；Reviewer 按当前阶段维护候选并记录；Owner 决定最终译法和批准状态。
- 具体语境与 `approved` 发生真实冲突时，可采用有依据的暂译并交接原文、位置、现行权威、暂译和理由；Owner 再次批准前不覆盖既有权威。
- 术语说明只保存可跨作品复用的消歧、概念及用法信息；具体底本疑点和已完成批次问题分别按对应流程分流。
