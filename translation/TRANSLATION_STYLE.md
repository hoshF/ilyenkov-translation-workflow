# 中文翻译规范

本文件只适用于 **Operator**，规定中文译文的内容、表达、结构和术语标准。

单篇文章依 [`ARTICLE_TRANSLATION_WORKFLOW.md`](ARTICLE_TRANSLATION_WORKFLOW.md)，书籍依 [`TRANSLATION_WORKFLOW.md`](TRANSLATION_WORKFLOW.md)。阶段权限、工件与停止条件按对应流程执行。

---

## 0. 核心原则

翻译优先级：

```text
准确性
> 语言自然度
> 术语一致性
```

发生冲突时，高优先级原则优先。

Operator 的任务是：

- 准确翻译原文；
- 写成自然、清楚的现代汉语；
- 遵守现有 glossary 权威；
- 保持底本与译文结构对应；
- 将无法可靠决定的问题按流程交给后续角色。

流畅、统一和个人偏好都以原文意义为限。

---

## 1. 结构与格式

### block

底本已有 block-id 时，译文逐 block 对应。

- block-id 保持不变；
- block 顺序保持不变；
- block 数量保持不变；
- 正文留在原 block 内；
- block-id 单独一行；
- block-id 后紧接对应正文，中间不空行；单篇文章注释定义前的 `note-label` 标记依 [`PUNCTUATION.md`](PUNCTUATION.md) 写在 block-id 与该注释定义之间，图注前的 `figure-caption` 标记依下文写在 block-id 与该图注之间，其他正文直接紧接 block-id。

block 已在成书预处理中按语义单元划分，翻译阶段按语义单元理解 block。

单篇文章原文没有 block-id 时，以自然段和结构元素保持对应，以小节、段首短引或注释编号定位问题。

### 段落

- 一个自然段写成一行；
- 段落之间空一行；
- 原文文件中的纯排版硬换行并入所在段落。

### 结构元素

保持原文中的结构身份和相对位置，包括：

- 标题；
- 署名；
- 日期；
- 列表；
- 引文；
- 脚注标记；
- 脚注定义；
- 参考文献引证；
- 分隔符。

图注照录原文图注，作者、刊物和来源网站所加图注照原样保留；图注只写原文已有的内容。图表编号标签依 [`PUNCTUATION.md`](PUNCTUATION.md)。

照录的原文图注由图注段落前单独一行的 `<!-- figure-caption -->` 标出：

```markdown
![替代文字](img-8.png)

<!-- figure-caption -->
照录的原文图注
```

- 标记只用于照录的原文图注，所在段落紧接其所说明的图片段落之后；
- 图注段落已有 block-id 时，顺序为 block-id、标记、图注，三者之间不空行；
- 多幅图片共用一条图注时，标记随原文图注留在原文所在的图片之后；
- 图注文字及原文的加粗、斜体等写法照录，显示或排版时统一图注样式；
- 标记是编辑元信息，不属于译文正文；标记前为图片段落、后为图注段落。

### 单篇文章的标题、摘要与引言

单篇文章的正文范围依 [`ARTICLE_TRANSLATION_WORKFLOW.md`](ARTICLE_TRANSLATION_WORKFLOW.md)。

单篇文章的一级标题与 `work.json` 的 `title_zh` 一致；原文副标题已含在 `title_zh` 中时，由一级标题呈现。

保留原文的章节、附录和小标题；内容性小节标题只用原文已有的，`## 引言` 依下文，`## 注释` 等技术性结构标题照常使用。原文小节编号保留：“I. 标题”这类带标题的编号写作“一、标题”；只由罗马数字构成的节号保持原样。

单篇文章译文中的摘要标签写作 `**摘要**`，单独成段；摘要正文从下一段开始。

关键词标签写作 `**关键词：**`，与关键词写在同一段，作为普通段落。

摘要与关键词的标签规范化保持原文内容和位置。

文章开篇没有标题、承担引言功能且后文已有正文分节时，在开篇正文前使用二级标题 `## 引言`：

- 原有行内“引言”标签改为该标题；
- 已有的摘要、关键词和题记保持在“引言”标题之前；
- 正文内容和既有章节编号保持不变。

正文直接进入首个实质分节、全文没有正文分节，或开篇是叙事性序幕等不承担引言功能的体裁时，开篇保持原样。

上述一级标题、小节编号写法、摘要与关键词标签和引言标题是单篇文章的 Markdown 结构规范化；其余部分保持原文结构身份和相对位置。

### 单篇文章的参考文献

单篇文章译文的参考文献使用中文信息在前、外文原题括注的形式。Owner 已逐篇裁决的著录体例优先适用。

- 保留底本的条目顺序、编号体系和分表结构；
- 作者、题名、责任说明、出版地和出版社译成中文，姓名与术语使用现行 glossary 权威；
- 篇名、书名先写中文译名，随后括注外文原题；期刊名和丛书名译成中文时，同样括注原刊名或原丛书名；
- 保留底本所引版本的年份、版本、卷期、页码、编者、译者和丛书信息；
- 著录底本实际引用的版本；
- `forthcoming` 等出版状态按底本译出；
- 无编号的条目每条写成一个自然段，条目之间空一行；数字编号制的条目可以写成有序列表项，条目之间空一行，列表编号与底本编号逐项一致时才使用有序列表；
- 修复条目内部的纯排版断行，每个条目保持独立；
- 作者—年份制引证中的作者名同步译成中文，并与文末条目唯一对应；数字编号制保持底本体系；
- 题名或责任信息无法可靠判断时，保留原文并按对应流程交接。

参考文献中的姓名缩写、标点和引证形式依 [`PUNCTUATION.md`](PUNCTUATION.md)。

脚注标记与脚注定义完整对应；原刊有注文而正文没有对应注码时依 [`PUNCTUATION.md`](PUNCTUATION.md) 处理，注文保留。

单篇文章中的原文注释使用在当前文档内唯一的纯数字 ID，ID 与原刊注码的对应及例外依 [`PUNCTUATION.md`](PUNCTUATION.md)；原刊已有的数字编号体系照原刊保留，异常编号照原刊保留；非数字注可以转换为数字注码，原刊数字注码保持不变。注释定义按经核验的原文注文顺序排列。显示注码与技术 ID 不同时，经单篇裁决使用 `PUNCTUATION.md` 规定的 `note-label` 标记，标记是编辑元信息，不属于译文正文。书籍脚注保留预处理结构中的作用域 ID。脚注与参考文献引证的编号形式和对应关系依 [`PUNCTUATION.md`](PUNCTUATION.md)。

脚注和注码以原文为限。

标点与字体样式转换依 [`PUNCTUATION.md`](PUNCTUATION.md)。

### 书籍的书目、参考文献与索引

开始书目、参考文献或索引批次前，读取本书已裁决的著录体例及相关专名约定。没有既定体例时，书目与参考文献采用中文信息在前、外文原题括注的形式：

- 作者、题名、责任说明、出版地和出版社译成中文；题名、刊名和丛书名译成中文时，随后括注底本的外文原名；
- 保留底本的条目顺序、编号体系、分表结构及 block 对应；
- 完整保留实际引用版本的年份、版本、卷期、页码、编者、译者、丛书和出版状态，以底本著录为准；
- 姓名依 `PUNCTUATION.md` 保持全名、缩写和姓氏的信息粒度，正文以底本给出的信息为准；
- 同一人物、作品和机构在正文、书目、参考文献与索引中使用相应的中文译名；核对身份及版本，区分同姓、同名或近似题名的不同对象；
- 作者—年份引证保留年份及同年区分标记，数字编号制保留编号；底本已有明确对应时，译文名称对应到该条目；
- 名称、题名或责任信息无法可靠判断时保留原文，按书籍流程登记或交接；底本自身的不一致按原文疑点处理。

索引保留底本的排序、层级、交叉参照及原书页码、页码区间。正文、注释和索引中指向原书的页码，翻译阶段照录原书页码；译本页码由排版阶段处理。

核对其他已完成批次中的对应位置时，作必要的身份和名称对照；发现具体译文问题依书籍流程登记。

## 2. 准确性

准确表达原文的：

- 命题内容；
- 论证顺序；
- 概念区别；
- 逻辑关系；
- 限定范围；
- 指代关系；
- 施动关系；
- 否定、条件和程度；
- 语气与情态；
- 转折、反讽、强调等修辞关系。

译文与原文内容对应：

- 原文内容完整译出，译文内容以原文为限；
- 解释、标签和结论只写原文已有的（单篇文章引言标题规范化依第 1 节）；
- 逻辑关系随原文；
- 保留具有语义作用的重复、小词和限定；
- 原文不同概念分别译出。

### 引文

作者引用其他文本时，以**作者实际引用的文本**为翻译对象。

保留：

- 作者实际引用的内容；
- 作者自己的省略；
- 作者自己的强调；
- 作者自己的改写；
- 卷次、页码及其他引文信息。

引文以作者实际引用的文本为准，其他版本、通行译本和经典表述只作参考。

本书其他位置引用同一文字时，核对相同概念和可比语境中的关键术语。不同版本、删节、强调及作者改写分别保留，各引文按各自文本翻译。对照已完成批次用于核对；需修改该批次时按书籍流程登记。

### 多种可能读法

原文存在多种可能读法时：

1. 根据句法判断；
2. 检查近邻上下文；
3. 检查全文论证关系；
4. 采用证据最充分的解释。

无法可靠判断时，在 handoff 写明可能的读法及当前选择，按对应流程交后续角色。

疑似原文、OCR 或底本错误，书籍记入 `source-issues.json`，单篇文章记入 `handoff.md` 的原文疑点；正文照底本翻译。

## 3. 语言自然度

在准确性成立的前提下，译文应：

- 符合现代汉语句法；
- 自然；
- 清楚；
- 通顺；
- 保持原文的论证层次。

可以根据中文表达需要调整：

- 语序；
- 主从结构；
- 长句内部组织；
- 连接方式。

调整时保持：

- 原义；
- 概念区别；
- 限定关系；
- 论证完整；
- 谨慎或确定程度；
- 有意义的重复；
- 原文内容范围。

句法按现代汉语组织，语体与原文相称。

## 4. 术语

翻译前读取 `glossary/` 中与当前文本相关的条目。

### approved

`approved` 条目的 `zh_preferred` 是现行权威译法。

在相同或可比语境中，保持：

- 同一概念的一致性；
- 固定表达的一致性；
- 成组对立概念的对应关系。

### provisional

`provisional` 是候选译法，供参考。

既有 `needs_review` 条目是待核参考，按 `GLOSSARY_RULES.md` 只读使用。

### 判断原则

术语对应以**实际概念和语境**为准。

- 保持原文的理论区别；
- 新译法经 Owner 裁决后成为权威；
- 多义词按语境选择中文。

原文未严格使用专业术语、但实际明确指向已有理论概念时，使用相应中文学科通名。

### 与 approved 发生真实冲突

当前具体语境与现有 approved 译法确实冲突时：

1. 先确认属于同一概念和可比语境；正常语境变体与权威并存；
2. 可以按原文和当前语境采用有依据的暂译；
3. 在 handoff 中写明：
   - 原文；
   - 位置；
   - 当前语境；
   - 现有 glossary 权威；
   - 当前暂译及建议；
   - 理由。
4. glossary 修改和长期译法由 Owner 裁决。

### 裁决范围与条目冲突

术语裁决的生效范围及多个 `approved` 条目的冲突，依 [`GLOSSARY_RULES.md`](../glossary/GLOSSARY_RULES.md)「裁决范围」与「多个 approved 条目的适用判断」。Operator 按获准范围翻译，将需延续的作品约定交接给后续角色；同一概念、同一适用范围的条目冲突，在 handoff 中列出相关条目、当前译法及待裁决范围，交 Owner 处理 glossary。

glossary 的归属、状态与维护依 [`glossary/GLOSSARY_RULES.md`](../glossary/GLOSSARY_RULES.md)。

## 5. 范畴与概念表达

理论范畴的中文形式根据实际句法功能处理。

- 作为术语名称直接被提及时，可以使用引号；
- 作修饰语时，使用符合中文句法的表达；
- 作实体化范畴时，采用能够明确表示其范畴身份的形式。

不同句法功能使用相应的中文结构。

具体术语已有 glossary 规定时，以 glossary 为准。

---

## 6. 问题分流

翻译过程中按问题性质处理：

| 问题                        | 去向                 |
| --------------------------- | -------------------- |
| 当前译法存在真实不确定性    | handoff              |
| glossary 新增或修改建议     | handoff              |
| 原文、OCR、底本疑点         | 书籍：`source-issues.json`；文章：handoff 原文疑点 |
| 已有 approved 与当前语境冲突 | handoff              |

以下工作由其他角色或阶段承担：

- Reviewer 审校；
- Owner 裁决；
- glossary 最终权威修改；
- 已完成批次回改与全书统稿。

---

## 7. 完成条件

Operator 完成当前文章或书籍批次翻译时，满足：

- 当前文章全文或当前批次全部 unit 已翻译；
- 底本与译文结构对应正确；已有 block-id 时编号、顺序和数量一致；
- 译文符合本文件的准确性要求；
- 译文符合现代汉语表达；
- 已有 approved 术语已按规则处理；
- 原文疑点已按流程分流；
- 需要 Reviewer 知道的不确定问题已准备进入 handoff。

完成后依文章或书籍的对应流程进入后续 Operator 步骤。
