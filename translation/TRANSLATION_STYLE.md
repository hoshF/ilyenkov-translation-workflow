# 中文翻译规范

本文件只适用于 **Operator**，规定中文译文的内容、表达、结构和术语标准。

单篇文章依 [`ARTICLE_TRANSLATION_WORKFLOW.md`](ARTICLE_TRANSLATION_WORKFLOW.md)，书籍依 [`TRANSLATION_WORKFLOW.md`](TRANSLATION_WORKFLOW.md)。阶段权限、工件与停止条件按对应流程执行。

---

## 0. 核心原则

翻译优先级：

```text
准确性
> 语言自然度
> 术语一致性
```

发生冲突时，高优先级原则优先。

Operator 的任务是：

- 准确翻译原文；
- 写成自然、清楚的现代汉语；
- 遵守现有 glossary 权威；
- 保持底本与译文结构对应；
- 将无法可靠决定的问题按流程交给后续角色。

不得为了流畅、统一或个人偏好改变原文意义。

---

## 1. 结构与格式

### block

底本已有 block-id 时，译文必须逐 block 对应。

- block-id 保持不变；
- block 顺序保持不变；
- block 数量保持不变；
- 不跨 block 合并、拆分或移动正文；
- block-id 单独一行；
- block-id 后紧接对应正文，中间不空行。

block 已在成书预处理中按语义单元划分。翻译阶段不得把 block 当作 PDF 行、OCR 行或排版行重新解释。

单篇文章原文没有 block-id 时不强制补建，以自然段和结构元素保持对应，以小节、段首短引或注释编号定位问题。

### 段落

- 一个自然段写成一行；
- 段落之间空一行；
- 不因原文文件中的纯排版硬换行自行建立新段落。

### 结构元素

保持原文中的结构身份和相对位置，包括：

- 标题；
- 署名；
- 日期；
- 列表；
- 引文；
- 脚注标记；
- 脚注定义；
- 参考文献引证；
- 分隔符。

### 单篇文章的摘要与引言

单篇文章译文中的摘要标签写作 `**摘要**`，单独成段；摘要正文从下一段开始。

文章开篇没有标题、承担引言功能且后文已有正文分节时，在开篇正文前使用二级标题 `## 引言`。

- 原有行内“引言”标签改为二级标题，不重复添加；
- 已有的署名、摘要、关键词、资助说明和题记保持在“引言”标题之前；
- 全文没有正文分节、后文只有注释或参考文献标题时，不添加“引言”；
- 正文直接进入首个实质分节时，不添加“引言”；
- 叙事性序幕或其他不承担引言功能的特殊体裁开篇，不强制添加“引言”；
- 不改动正文内容和既有章节编号。

上述摘要分段与引言标题是单篇文章的 Markdown 结构规范化；除此之外，保持原文结构身份和相对位置。

### 单篇文章的参考文献

单篇文章译文的参考文献使用中文信息在前、外文原题括注的形式。

- 作者、题名、责任说明、出版地和出版社译成中文，姓名与术语使用现行 glossary 权威；
- 篇名、书名先写中文译名，随后括注外文原题；期刊名和丛书名译成中文时，同样括注原刊名或原丛书名；
- 保留底本所引版本的年份、版本、卷期、页码、编者、译者和丛书信息；
- 不用其他版本或中文译本替换底本实际引用的版本；
- `forthcoming` 等出版状态按底本译出，不依据后来的出版事实回改；
- 每条参考文献写成一个自然段，条目之间空一行；修复条目内部的纯排版断行，不合并不同条目；
- 作者—年份制引证中的作者名同步译成中文，并与文末条目唯一对应；数字编号制保持底本体系；
- 题名或责任信息无法可靠判断时，保留原文并按对应流程交接，不猜译。

参考文献中的姓名缩写、标点和引证形式依 [`PUNCTUATION.md`](PUNCTUATION.md)。

脚注标记与脚注定义必须完整对应。

单篇文章中的原文注释按正文首次出现顺序使用连续的纯数字 ID；书籍脚注保留预处理结构中的作用域 ID。脚注与参考文献引证的编号形式和对应关系依 [`PUNCTUATION.md`](PUNCTUATION.md)。

不得新增原文不存在的脚注。

标点与字体样式转换依 [`PUNCTUATION.md`](PUNCTUATION.md)。

## 2. 准确性

准确表达原文的：

- 命题内容；
- 论证顺序；
- 概念区别；
- 逻辑关系；
- 限定范围；
- 指代关系；
- 施动关系；
- 否定、条件和程度；
- 语气与情态；
- 转折、反讽、强调等修辞关系。

不得：

- 漏译；
- 增译；
- 添加原文没有的解释；
- 添加原文没有的标签或结论（本文件规定的单篇文章引言标题规范化除外）；
- 因中文表达方便而改变逻辑关系；
- 无依据弱化或删除具有语义作用的重复、小词或限定；
- 把原文不同概念压平为同一个概念。

### 引文

作者引用其他文本时，以**作者实际引用的文本**为翻译对象。

必须保留：

- 作者实际引用的内容；
- 作者自己的省略；
- 作者自己的强调；
- 作者自己的改写；
- 卷次、页码及其他引文信息。

不得用其他版本、通行译本或记忆中的经典表述替换作者实际引用的文本。

### 多种可能读法

原文存在多种可能读法时：

1. 根据句法判断；
2. 检查近邻上下文；
3. 检查全文论证关系；
4. 采用证据最充分的解释。

无法可靠判断时，不得把猜测写成唯一确定的译文解释；按对应流程写入 handoff。

疑似原文、OCR 或底本错误，书籍记入 `source-issues.json`，单篇文章记入 `handoff.md` 的原文疑点，不以翻译偏好自行修改正文。

## 3. 语言自然度

在准确性成立的前提下，译文应：

- 符合现代汉语句法；
- 自然；
- 清楚；
- 通顺；
- 保持原文的论证层次。

可以根据中文表达需要调整：

- 语序；
- 主从结构；
- 长句内部组织；
- 连接方式。

但不得因此：

- 改变原义；
- 压平概念区别；
- 删除限定关系；
- 简化论证；
- 改变谨慎或确定程度；
- 把有意义的重复改写成不同概念；
- 加入解释性内容。

不得机械模仿俄语句法。

也不得为了制造“学术感”而无依据使用生硬、晦涩或偏离原义的表达。

## 4. 术语

翻译前读取 `glossary/` 中与当前文本相关的条目。

### approved

`approved` 条目的 `zh_preferred` 是现行权威译法。

在相同或可比语境中，应保持：

- 同一概念的一致性；
- 固定表达的一致性；
- 成组对立概念的对应关系。

### provisional

`provisional` 只表示候选译法，不构成强制翻译依据。

既有 `needs_review` 条目只作为待核参考，不构成权威；按 `GLOSSARY_RULES.md` 只读使用。

### 判断原则

术语对应以**实际概念和语境**为准，不以俄文表面词形机械判断。

不得：

- 因中文近义词更顺口而抹去原文理论区别；
- 自行创造与现有 approved 权威竞争的新译法；
- 为追求表面统一而强迫多义词在所有语境使用同一个中文词。

如果原文未严格使用专业术语，但实际明确指向已有理论概念，使用相应中文学科通名。

### 与 approved 发生真实冲突

若当前具体语境与现有 approved 译法确实冲突：

1. 先确认属于同一概念和可比语境；正常语境变体不作为权威冲突；
2. 可以按原文和当前语境采用有依据的暂译；
3. 在 handoff 中写明：
   - 原文；
   - 位置；
   - 当前语境；
   - 现有 glossary 权威；
   - 当前暂译及建议；
   - 理由。
4. 不直接修改 glossary，不把暂译自动作为新的长期权威；最终处理由 Owner 裁决。

glossary 的归属、状态与维护依 [`glossary/GLOSSARY_RULES.md`](../glossary/GLOSSARY_RULES.md)。

## 5. 范畴与概念表达

理论范畴的中文形式应根据实际句法功能处理。

- 作为术语名称直接被提及时，可以使用引号；
- 作修饰语时，使用符合中文句法的表达；
- 作实体化范畴时，采用能够明确表示其范畴身份的形式。

不得仅为形式统一，把不同句法功能机械翻译成完全相同的中文结构。

具体术语已有 glossary 规定时，以 glossary 为准。

---

## 6. 问题分流

翻译过程中按问题性质处理：

| 问题                        | 去向                 |
| --------------------------- | -------------------- |
| 当前译法存在真实不确定性    | handoff              |
| glossary 新增或修改建议     | handoff              |
| 原文、OCR、底本疑点         | 书籍：`source-issues.json`；文章：handoff 原文疑点 |
| 已有 approved 与当前语境冲突 | handoff              |

Operator 不承担：

- Reviewer 审校；
- Owner 裁决；
- glossary 最终权威修改；
- 已完成批次回改；
- 全书统稿。

---

## 7. 完成条件

Operator 完成当前文章或书籍批次翻译时，应满足：

- 当前文章全文或当前批次全部 unit 已翻译；
- 底本与译文结构对应正确；已有 block-id 时编号、顺序和数量一致；
- 译文符合本文件的准确性要求；
- 译文符合现代汉语表达；
- 已有 approved 术语已按规则处理；
- 原文疑点已按流程分流；
- 需要 Reviewer 知道的不确定问题已准备进入 handoff。

完成后依文章或书籍的对应流程进入后续 Operator 步骤。

不得自行增加 Reviewer、Owner 或统稿阶段的工作。
