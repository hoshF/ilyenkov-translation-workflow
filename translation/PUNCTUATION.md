# 俄译中标点与字体样式转换规则

中文正文标点依 GB/T 15834。

中文全角标点前后不人为添加空格。

---

## 1. 基本标点

| 俄文        | 中文                                  |
| ----------- | ------------------------------------- |
| `,`         | `，`；并列词或短语时按中文句法用 `、` |
| `.`         | `。`                                  |
| `;`         | `；`                                  |
| `:`         | `：`                                  |
| `?`         | `？`                                  |
| `!`         | `！`                                  |
| `( )`       | `（ ）`                               |
| `...` / `…` | `……`                                  |

转换根据实际句法功能判断，不做纯字符替换。

不得因为原文使用半角标点就在中文正文中保留半角形式。

---

## 2. 引号与书名号

俄文 `« »`、`“ ”`、`„ “`、`" "` 都可能承担不同功能。

根据实际内容转换，不保留其原有引号样式。

| 功能                       | 中文处理                                 |
| -------------------------- | ---------------------------------------- |
| 普通引文                   | `“……”`                                   |
| 引文中的内层引文           | `‘……’`                                   |
| 书名、刊名                 | `《……》`                                 |
| 独立称引的正式篇名、章名   | `《……》`                                 |
| 书名号中的作品名           | `〈……〉`                                 |
| 正式档案文件名、档案件名   | `《……》`                                 |
| 编者俗称、描述性名称、临时标签 | `“……”`                               |
| 反语、特殊含义             | `“……”`                                   |
| 一般机构名、产品名、绰号   | 通常不加符号；确需强调特殊称谓时用 `“……”` |

例如：

```text
«Капитал»
→ 《资本论》
```

```text
«наука» такого рода
→ 这种“科学”
```

### 引号与句末点号

引文本身构成完整句子时：

```text
他说：“这是对的。”
```

引文只是当前句子的组成部分时：

```text
他说这“确实对”。
```

不得机械照搬俄文句点与 `»` 的相对位置。

---

## 3. 逗号与顿号

俄文逗号根据中文句法转换。

并列词或短语：

```text
Гегель, Фейербах и Маркс
→ 黑格尔、费尔巴哈和马克思
```

并列分句或一般停顿：

```text
Он пришёл, и мы начали.
→ 他来了，我们就开始了。
```

不得把所有俄文逗号机械转换为中文逗号。

---

## 4. 破折号与连接号

俄文 `—` 必须按语法功能处理。

不得统一转换成中文破折号。

| 俄文功能          | 中文处理                      |
| ----------------- | ----------------------------- |
| 省略系词 `быть`   | 补出“是”等中文系词            |
| `— это`           | 按语境译为“是”“就是”等        |
| 插入语            | 成对破折号，或按中文句法改括号 |
| 引文中的说话人插入 | 按中文引号和句法处理          |
| 行首对话          | 改用中文引号                  |
| 解释、补充、话题转换 | `——`                        |
| 结果、对比        | 根据中文语气使用 `，` 或 `——` |

例如：

```text
Москва — столица.
→ 莫斯科是首都。
```

```text
Конкретное — это синоним…
→ 具体的东西是……的同义语。
```

```text
Труд — вот источник.
→ 劳动——这才是源泉。
```

### 破折号和连接号

| 中文符号 | 用途                           |
| -------- | ------------------------------ |
| `——`     | 破折号：解释、补充、话题转换等 |
| `—`      | 连接号：连接相关项目           |

例如：

```text
17—18 世纪
洛克—爱尔维修
主体—实体
生物—人类学
```

原文中的 `–` 如果只是字体或转换造成的不同横线字符，根据实际功能归入上述规则。

---

## 5. 连字符与专名

俄文连字符按功能处理。

| 情形                                     | 中文处理                   |
| ---------------------------------------- | -------------------------- |
| 构词连字符，如 `по-новому`、`кто-то`、`из-за` | 不保留                 |
| 复合人名                                 | 按既定中文译名处理，通常使用 `·` |
| 数字区间                                 | 使用连接号 `—`             |
| 不换行连字符等技术字符                   | 按其实际语言功能处理       |

例如：

```text
Римский-Корсаков
→ 里姆斯基·科萨科夫
```

```text
1917-1921
→ 1917—1921
```

专名译法以 `glossary/` 为准。

已有稳定译名时不得现场重新音译。

---

## 6. 姓名与缩写

### 信息粒度

正文中的姓名信息不得超过原文实际提供的信息。

- 原文给全名 → 译完整姓名；
- 原文给缩写 → 保持缩写形式，不展开为全名；
- 原文只给姓氏 → 只译姓氏，不补缩写或名字。

glossary 中保存的完整姓名不得用于给正文补充原文没有的信息。

### 已知姓名的缩写

完整姓名能够从本书人物志、glossary 或可靠资料确认时，缩写按该姓名中文译名对应音节的首字转写，以 `·` 连接。

本书索引是证据之一；与正文、参考文献或其他可靠资料不一致时，不单独据以确认。确认结果需要校正底本给出的名字或身份时，按流程交 Owner，裁决前保留底本形式。

例如：

```text
Ильенков Эвальд Васильевич
→ 埃瓦尔德·瓦西里耶维奇·伊里因科夫
```

```text
Ильенкова Э. В.
→ 埃·瓦·伊里因科夫
```

```text
М. П. Баскин
→ 马·彼·巴斯金
```

```text
К. Маркса
→ 卡·马克思
```

### 无法确认姓名

完整姓名不能可靠确认时，保留西里尔字母缩写，并以 `·` 连接：

```text
В. И. Алексеев
→ В·И·阿列克谢耶夫
```

不得根据单个俄文字母建立默认中文首字规则。

---

## 7. 以人名命名的机构

中文通常按：

```text
地名 + 命名者 + 机构类别
```

处理。

例如：

```text
Одесское артиллерийское училище им. Фрунзе
→ 敖德萨伏龙芝炮兵学校
```

已有 glossary 权威时，以 glossary 为准。

---

## 8. 机构缩写

正文中的俄文机构缩写译为中文全称，不在正文保留俄文缩写。

原文缩写可在对应注释中说明，但不得补入底本之外的信息。

例如：

```text
ГУКАРТ[^i-3]
→ 炮兵司令员总局[^i-3]

[^i-3]: 原文缩写为ГУКАРТ。
```

已有项目注释或 glossary 规定时，不重复新增说明。

---

## 9. 省略号

俄文：

```text
...
```

或：

```text
…
```

统一转换为：

```text
……
```

即两个 U+2026。

规则：

- 位置依原文；
- 不自行移动；
- 后面不再另加句号。

---

## 10. 编者、译者与文献状态标记

正文中的附加文字必须明确责任来源。

| 类型               | 中文形式                  |
| ------------------ | ------------------------- |
| 原书编者补入正文的词语 | `〔……〕`              |
| 原书编者说明       | `〔……——原书编者〕`       |
| 原作者说明         | `〔……——原作者〕`         |
| 来源网站或原刊编者的编者按、注释 | 末尾写“——来源网站编者”或“——原刊编者” |
| 译本编者说明       | `〔……——译本编者〕`       |
| 译者短注           | `〔……——译注〕`           |
| 译者长注           | `[^zh-N]`，注末写“——译注” |
| 原版页码           | `〔数字〕`                |

原版页码只保留数字：

```text
〔125〕
```

不写成：

```text
〔第125页〕
```

### 原书编者插入

原文使用 `<...>` 表示编者补入文字时，译文转换为：

```text
〔……〕
```

### 原文删节

底本或其所引文本存在删节时，译文用：

```text
[…]
```

它表示**略去了原有文字**，与表示编者补入的 `〔……〕` 责任方向相反，二者不得混用，也不要写成正文省略号 `……`。

底本已以作者姓名或缩写署名的自注，例如 `— Р.К.`，继续按人物缩写译出，不必改写为「——原作者」。

### 手稿删除状态

原文使用 `{...}` 标记被划去、删除或保留为文献状态的文字时：

> 保留 `{...}`。

不得转换为：

- `〔……〕`
- 普通正文
- “删去”等自行添加的说明

除非底本另有明确责任说明。

不得让译者补充、原书编者补充和作者正文相互混淆。

---

## 11. 西文内容

以下内容内部继续使用自身的西文标点与空格：

- 西文著录；
- 外文原词；
- 公式。

例如：

```text
Bd. XIX. Leipzig, Meiner, 1932.
```

```text
«Beiträge zur marxistischen Erkenntnisstheorie» (Suhrkamp, Frankfurt, 1969)
```

中文与西文混排时：

- 不人为添加额外中西文空格；
- 标点按其所属内容体系处理；
- 西文著录内部的半角标点和空格不转成中文全角标点。

---

## 12. 编号与其他符号

### 注释与参考文献引证

| 类型                 | 正文形式                                   | 对应内容               |
| -------------------- | ------------------------------------------ | ---------------------- |
| 单篇文章的原文注释   | `[^N]`                                     | `[^N]: 注释正文`       |
| 译者长注             | `[^zh-N]`                                  | `[^zh-N]: 注释正文。——译注` |
| 数字编号制引证       | `[N]`、`[N，第×页]`、`[N；M]`、`[同上]`    | 文末对应编号的参考文献 |
| 作者—年份制引证      | `[作者，年份]`、`[作者，年份：页码]`        | 文末对应作者—年份条目  |

`[^N]` 与 `[N]` 是相互独立的编号系统，同号不表示二者相互对应。

单篇文章译文中的原文注释使用不带前导零的纯数字 ID。原刊已有的数字编号体系照原刊保留，包括编号、顺序、缺号、非 1 起始和分节、分页重新起编，不为排版统一、技术实现或输出显示而重编；数字化原文照原刊保留注码，不因译文的编号处理而修改：

- 原刊使用数字注码且注码与注文能一一对应时，ID 与原刊注码相同；原刊注码不从 1 起、存在缺号，或部分注释依正文范围省略时，其余注释保留原注码，不为连续而重编；
- 底本使用星号、字母、责任类别或其他非数字注码时，可以转换为数字注码，保持注文身份、对应关系和原有顺序，对应关系记入 handoff；全文没有原刊数字注码时，按正文首次出现顺序连续编号；与原刊数字注码并存时，转换后的编号不得与原刊数字注码重复，也不得使原刊数字注码偏移，转换方案经单篇裁决；数字化原文保留其注释系列和稳定 ID；译文在注文中保留编者、作者等责任说明，不以脚注 ID 承担该信息；
- 原刊注码重复、分章分节或分页重新起编、多条注释共用一个原刊注码，或其他无法以唯一纯数字 ID 无歧义表达时，ID 在当前文档内保持唯一，可以与原刊注码不同；原刊注码及其与注文的对应照原刊保留，显示注码经单篇裁决后用下述显示注码标记表达，裁决依据记入 handoff；不套用连续编号，不为 ID 唯一而改写原刊注码，不合并、遗漏或重新指派注文；输出格式不能表达裁决结果时，报告 Owner 并停止该项实施，不以错误编号发布；
- 原刊注码印刷错误、注码与注文的对应已经核实时，经 Owner 裁决按核实的对应关系显示，印刷事实记入原文疑点；
- 原刊有注文而正文没有对应注码时，照录注文，不在正文补加注码，注文末尾加 `〔原刊保留注文，正文未见对应注码——译本编者〕`。

注码不从 1 起、缺号、重复、重新起编、共用注码和无注码注文须经底本核验，并在 handoff 和原文疑点中记录；已人工核验的数字化原文、既有原文疑点、handoff 与历史裁决可作为核验依据。

注释定义按经核验的原文注文顺序排列，不按技术 ID 的数值排序。

### 显示注码标记

原刊印刷的注码、经核验和裁决的显示注码、Markdown 技术 ID 与输出格式中的锚点（如 HTML 锚点）是不同的概念。没有标记时，纯数字技术 ID 即显示注码；输出锚点由技术 ID 生成。

显示注码与技术 ID 不同时，经 Owner 单篇裁决，在该注释定义的前一行写标记，中间不空行：

```markdown
<!-- note-label: 1 -->
[^6]: 注释正文……
```

- 标记只作用于紧随其后的一条注释定义，`N` 为正整数，或原刊星号注的 `*`、`**`、`***`；
- 星号标记只用于原刊确以星号标示的注释，原刊标号未经核实的注释不使用标记；原刊星号注可以用星号标记保留原刊标号，不必转换为数字注码；
- 注释定义前已有 block-id 时，顺序为 block-id、标记、注释定义，三者之间不空行；标记不写在 block-id 之前，也不写在 block-id 与其他正文之间；
- 显示注码可以重复、缺号或不从 1 起，技术 ID 在全文内唯一；
- 只用于全部注释使用纯数字技术 ID 的单篇文章译文；
- 标记是编辑元信息，不属于译文正文；
- 只在显示注码不能由技术 ID 表达时使用，每个标记的裁决依据记入 handoff。

以下情况不得静默忽略，报告 Owner，并阻止该篇以错误注释发布：

- 标记的下一行不是注释定义，包括标记写在 block-id 之前；
- 标记孤立、重复或无法确定所属注释定义；
- 标记值不是正整数，也不是 `*`、`**`、`***`；
- 标记值与技术 ID 相同；
- 并非全部注释使用纯数字技术 ID 的文档使用标记；
- 同一技术 ID 重复定义；
- 正文引用没有对应的注释定义；
- 正文未引用的注文中又引用注释。

其他格式错误或注码与注文无法确定对应时，报告 Owner，不作推测。

书籍译文为避免跨单元冲突而使用的作用域 ID 依预处理结构保留，不强制改成纯数字。

参考文献引证不得改成脚注。脚注即使包含书目信息，也不得因此改成参考文献引证。

底本使用作者—年份制时，作者名随译文使用中文译名，年份及 `a`、`b` 等区分标记保持不变，页码范围使用连接号。不得把数字编号制与作者—年份制互相改换。

| 原文   | 中文处理                                 |
| ------ | ---------------------------------------- |
| `№ 5`  | 正文可译“第5号”；著录中可保留 `№ 5`      |
| `§ 12` | 正文可译“第12节”；著录中可保留 `§ 12`    |
| `%`    | 保留                                     |
| `’`    | 外文词中的撇号保留                       |

### 字母分项

俄文：

```text
а) б) в) г)
```

转换为：

```text
（a）（b）（c）（d）
```

即：

- 西里尔字母转为对应拉丁分项字母；
- 使用中文全角成对括号。

### 图表标签

图注、表题的编号标签写作 `图N：`、`表N：`，编号依原文。正文回指图表时写作“图N”“表N”或照原文括注形式，不加冒号。

## 13. 字体样式

底本样式只转换为 Markdown 记号；最终字体和版式由后续排版阶段处理。

| 底本样式        | Markdown |
| --------------- | -------- |
| 斜体            | `*…*`    |
| 粗体            | `**…**`  |
| 全大写          | `**…**`  |
| 空样式标记 `* *` | 删除    |
| 只包住孤立标点、无语义作用的样式标记 | 删除样式，保留标点 |

规则：

1. 样式范围必须逐处对应底本；
2. 不自行扩大到整句或整段；
3. 中文没有大小写，底本全大写统一记为 `**…**`；
4. 外文原词保留原文字形和相应样式；
5. 书名使用书名号，不再额外以 Markdown 样式表示。

例如：

```text
Das Kapital
→ 《资本论》
```

如果底本为：

```text
*Kant I.*
*causa finalis*
```

译文继续保留对应外文内容及斜体样式。
