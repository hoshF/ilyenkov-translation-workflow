# 译文成书排版规则

Operator 开始成书排版前必须完整阅读本文档。

本文件只适用于**译作成书内页**，规定 Markdown 到 LaTeX 的排版语义、字体关系、作品版式建立、校验与问题分流。

不处理：单篇文章排版、封面设计、翻译准确性、术语裁决和底本文字校订。

译文中的标点和源样式记号依 [`PUNCTUATION.md`](../translation/PUNCTUATION.md)。

# 一、排版架构

## 1. 分层

成书排版分为四层：

```text
Markdown 源记号
        ↓
排版语义
        ↓
LaTeX 语义命令
        ↓
template / 作品 .tex / 作品成书配置
```

Markdown 记录底本形态；成书阶段根据结构和功能确定排版语义，再由作品级排版实现决定最终视觉效果。

## 2. 判断原则

1. 先判断结构和功能，再判断字面形态。
2. 同一文字在不同结构位置可以使用不同排版语义。
3. 无法可靠判断时，保留底本原有的强调性质。
4. 同一结构在同一作品中保持一致。
5. 不因排版实现困难修改正确的译文 Markdown。

## 3. 底本版式与中文适配

中文译本内页以**底本版式系统**为作品级设计依据。

优先继承：

- 开本；
- 版心位置和比例；
- 天头、地脚、内外边距关系；
- 页眉和页码位置；
- 标题与目录层级；
- 正文、注释、附录、索引等部分的版式关系；
- 图片、图题和正文的位置关系；
- 稳定的留白和视觉节奏。

可以根据中文排印调整：

- 中文字体；
- 行距；
- 首行缩进和悬挂缩进；
- 中文标点禁则；
- 中西文混排；
- 长标题换行；
- 注号形态；
- 因汉字密度产生的必要间距。

不要求中文版与底本逐页对应。需要保留底本分页信息时，使用原页码标记。

## 4. 文件职责

### 通用 template

提供：

- LaTeX 语义命令；
- 字体路由；
- 通用排版能力；
- 通用默认实现。

### 作品 `.tex` / 作品成书配置

负责该书的具体排版，包括：

- 作品特有结构；
- 章节装配；
- 标题与目录关系；
- 公文结构；
- 图片组织；
- 底本版式还原；
- 作品特有参数和中文适配。

作品 `.tex` 可以手工维护。通用规则进入转换器或 template；作品特有规则保留在作品 `.tex` 或成书配置中。

### 环境与示例

排版环境由使用者提供 XeLaTeX、所用宏包、具备必要字符覆盖的字体和作品资源；字体的使用与分发权限须分别确认。

最小接口练习依 [`examples/minimal/README.md`](../examples/minimal/README.md)。正式作品须自行建立符合下述语义命令及字体关系的 template / preamble、章节装配和作品成书配置，不从示例编译成功推导正式成书完成。工具输入输出及检查范围依 [`scripts/README.md`](../scripts/README.md)。

# 二、Markdown 到排版语义

## 1. 行内样式

| Markdown | 功能 | LaTeX |
| --- | --- | --- |
| `*…*` | 正文强调 | `\bookemph{}` |
| `*…*` | 署名、著录作者、附属责任信息 | `\bookapparatus{}` |
| `**…**` | 正文强调 | `\bookstrong{}` |
| `**…**` | 章末或文末署名 | `\bookapparatus{}` |
| `**…**` | 发言人标签 | `\bookspeaker{}` |
| `**…**` | 人物志、辞典式词头 | `\bookentry{}` |

无法可靠判断时：

```text
*…*   → \bookemph{…}
**…** → \bookstrong{…}
```

## 2. 结构记号

| Markdown | 排版语义 | LaTeX |
| --- | --- | --- |
| 独立 `* * *` | 结构分隔 | `\bookseparator` |
| 行首 `- ` | 条目式清单 | `\bookitem{}` |
| 行首 `> ` | 作品定义的附属材料块 | `\booknote{}` |
| 行尾 `\` | 诗行强制换行；含此记号的块整块为诗行块 | `\bookverse{}`，块内以 `\\` 断行 |
| `![…](…)` | 图片 | `\bookfigure{}` |
| `[^id]` / `[^id]:` | 脚注 | 正式脚注结构 |

`- `、`> ` 和图片的具体功能由作品结构决定。其他作品出现不同用法时，在作品级排版中定义。

## 3. 连续下划线

连续下划线只有在核对底本后确认其表示手稿横线或图形性分隔时，才转换为：

```latex
\bookinlinerule
```

具体识别范围由作品级排版定义。

## 4. 图片

Markdown 图片进入：

```latex
\bookfigure{}
```

以下属性由底本版式和作品级排版决定：

- 位置与是否浮动；
- 宽度和高度；
- 对齐；
- 上下留白；
- 图题关系。

正文中的手稿图、示意图等应保持其与正文的语义位置关系。

## 5. 结构元数据

例如：

```text
<!-- text-layer: ... -->
```

只用于结构判断，不进入正文、目录、页眉或最终 PDF。

# 三、功能语义

## 1. 正文强调

正常句子内部、参与当前语法结构，且不承担标题、署名、标签、词头或著录功能的样式文字，按正文强调处理：

```text
*…*   → \bookemph{}
**…** → \bookstrong{}
```

## 2. 署名、落款和著录

明确承担作者、责任者、文献著录等附属信息功能时使用：

```latex
\bookapparatus{}
```

判断依据是文献结构和上下文。

## 3. 发言人标签

会议记录、讨论记录、速记稿中的发言导航标签使用：

```latex
\bookspeaker{}
```

排版时应避免标签与其后发言正文分页分离。

## 4. 人物志和辞典式词头

人物志、人物表、辞典式条目的词头使用：

```latex
\bookentry{}
```

## 5. 公文结构

信件、通知、命令、申请、档案记录等文本可使用：

| 功能 | 命令 |
| --- | --- |
| 机关抬头、文种名 | `\bookletterhead{}` |
| 标题下说明、日期等 | `\booksubtitle{}` |
| 收信人、呈报对象 | `\bookaddressee{}` |
| 正文后的落款块 | `\booksignature{}` |

机关抬头和文种名不作为章节标题，不进入目录或书眉。多行落款作为一个结构块处理。

# 四、LaTeX 语义命令

## 1. 字体型命令

| 命令 | 功能 | 汉字 | Cyrillic | Latin |
| --- | --- | --- | --- | --- |
| `\bookemph{}` | 斜体型正文强调 | 黑体 | 黑体 | Italic |
| `\bookstrong{}` | 粗体型正文强调 | 黑体 | 黑体 | Bold |
| `\bookapparatus{}` | 署名、著录等附属信息 | 楷体 | 楷体 | Italic |
| `\footnoteemph{}` | 脚注中的附属著录信息 | 楷体 | 楷体 | Italic |
| `\bookspeaker{}` | 发言人标签 | 黑体 | 黑体 | Bold |
| `\bookentry{}` | 人物志、辞典式词头 | 黑体 | 黑体 | Bold |

Cyrillic 并入 CJK 字符类，随所在语义命令的汉字字体走；Latin 单独使用对应 Roman / Italic / Bold 字面。

每一种汉字语义字体都必须覆盖所需 Cyrillic 字符。

## 2. 结构型命令

| 命令 | 功能 |
| --- | --- |
| `\bookitem{}` | 条目式清单 |
| `\booknote{}` | 随正文附属材料 |
| `\bookverse{}` | 诗行块 |
| `\bookseparator` | 独立结构分隔 |
| `\bookinlinerule` | 行内图形分隔 |
| `\bookfigure{}` | 图片 |
| `\bookletterhead{}` | 公文抬头 |
| `\booksubtitle{}` | 公文说明行 |
| `\bookaddressee{}` | 收信人、呈报对象 |
| `\booksignature{}` | 落款块 |

语义命令只表达功能。字号、字重、缩进、行距、对齐、留白、图片尺寸、分隔线长度和栏数由 template 或作品级排版实现决定。

## 3. 字体实现

中文正文强调不用机械倾斜宋体模拟 italic。

底本 italic：

```text
汉字      → 黑体
Cyrillic  → 黑体
Latin     → Italic
```

底本 bold / ALL CAPS：

```text
汉字      → 黑体
Cyrillic  → 黑体
Latin     → Bold
```

署名、落款和著录附属信息：

```text
汉字      → 楷体
Cyrillic  → 楷体
Latin     → Italic
```

需要黑体时指定明确字重。

`AutoFakeBold` 与 `AutoFakeSlant` 只作为正文主字体 fallback，不作为正式语义实现。

# 五、转换与作品 `.tex`

## 1. Markdown 与 `.tex` 的边界

Markdown 已有明确记号的内容，由转换器转换为对应语义命令。

Markdown 没有专用记号、但可以根据作品结构可靠判断的排版语义，可以直接在作品 `.tex` 中实现。

正确的译文 Markdown 不因排版需要改写。

## 2. 转换器边界

转换器输出语义命令，不直接把具体字体、字号和版式参数写入正文。

例如正文强调输出：

```latex
\bookemph{}
```

具体视觉实现由 template / 作品级排版负责。

转换诊断分为阻断错误、警告和待人工处理事项。正常脚注续段等提示不作为转换失败；
脚注无定义、数字注文未排入或注号不连续等尚未解决的转换问题，必须返回非零状态，
不得写入或覆盖正式输出。

正式输出使用 `-o`，不以标准输出重定向覆盖已有成书文件。需要不完整草稿时，显式指定
`--draft-output 临时目录/章节.draft.tex`；草稿路径须独立、以 `.draft.tex` 结尾，且不能是既有文件
或脚本所在仓库的 `book/projects/`、`book/templates/` 内的路径。外部工程不得据此推定同样受自动路径保护，须另选独立临时目录。草稿输出保留未解决问题，返回非零状态，
不作为完整转换或验收通过的依据。

跨单元注释、标题注及已确认底本缺陷按明确裁决在作品 `.tex` 中处理；不猜补、不静默省略，
不为通过转换检查改写正确的译文 Markdown。

## 3. 标题与目录

正文标题与目录条目是两个排版层级。

正文标题内部样式可以保留；目录使用纯标题文本，再由目录自身样式排版。

## 4. 标点

标点内容依 `PUNCTUATION.md`。成书阶段保持已经确定的中文标点、西文著录标点、外文原词内部空格、破折号 `——` 和连接号 `—`。

## 5. 分块错误

如果成书时发现错误分块或结构记号使用错误，应返回对应源层修正，不在 `.tex` 中掩盖。

涉及 block 合并时：

- 保留该组第一个 block id；
- 删除被吸收的 block id；
- 不重新编号。

修正后保持底本 Markdown 与译文 Markdown 的 block-id 序列一致。

# 六、作品版式建立

每一本书在确定最终版式前，先检查底本代表页，覆盖正文、目录、标题、注释、特殊文献结构、图片、索引和附录等主要版式类型。

作品成书配置至少记录：

```text
开本
版心
页边距
正文尺寸
行距
首行缩进
页眉
页码
标题层级
目录
脚注 / 注释
列表
图片
索引
作品特有结构
```

底本参数能够直接保留的直接采用。因中文排印需要调整时，记录底本值和中文值。

# 七、校验

## 1. 结构与源码

确认：

- 实际使用的 Markdown 结构和样式记号均已落地；
- `.tex` 和 PDF 中没有误输出的 Markdown / HTML / 中间层标记；
- 脚注、图片和结构元数据处理正确。

## 2. 字体

从最终 PDF 核对：

- 汉字字体正确；
- Cyrillic 随对应汉字字体；
- Latin 字面正确；
- 同一语义全书一致；
- mixed-script 对象各侧样式一致。

## 3. 编译

检查：

- missing glyph；
- Overfull；
- 明显异常的 Underfull。

异常必须定位到具体结构或版式原因。

转换或编译退出成功只表示相应程序未发现其已实现检查中的阻断错误，不代替结构、字体和版面校样。

## 4. 版面校样

抽查各类代表性页面，重点检查：

- 正文和长标题；
- 目录；
- speaker / entry / apparatus / note / item；
- separator / inline rule / figure；
- 脚注；
- 章首章末；
- 页眉页码；
- 索引。

重点处理标题、标签、词头、图片与正文之间的分页关系，以及异常留白、脚注拥挤和版心溢出。

版心以多数正文行形成的稳定边界判断，不以单个悬挂标点作为越界依据。

# 八、问题分流

| 问题 | 处理位置 |
| --- | --- |
| Markdown → LaTeX 映射错误 | 转换器 |
| LaTeX 语义命令实现错误 | template / preamble |
| 项目通用排版规则缺失 | 本文件 |
| 某作品特有版式需求 | 作品 `.tex` / 成书配置 |
| 译文内容或译文体例错误 | `review-notes.json` |
| Markdown 结构记号使用错误 | `review-notes.json` |
| glossary 问题 | `glossary/` |
| 原文、OCR、数字化问题 | `source-issues.json` |
| 底本换行造成错误分块 | `source-issues.json` |

# 九、完成条件

成书排版完成时确认：

- 已完成底本版式测量并建立作品级排版参数；
- 中文适配项能够追溯到底本；
- Markdown 内容未因排版被改写；
- 所有实际使用的结构和样式均已正确落地；
- LaTeX 语义命令与最终字体一致；
- 图片、目录、公文、索引等作品结构排版正确；
- PDF 无 missing glyph 和未处理的源码标记；
- 无明显版心溢出或异常分页；
- 所有发现的问题均进入正确处理层。

满足以上条件后，成书排版阶段完成。

成书排版完成不表示翻译最终校阅完成。最终校阅的范围、阶段和完成条件由 Owner 明确指定；
不得从编译成功、已有 PDF 或版面抽查推导最终质量验收或发布许可。
