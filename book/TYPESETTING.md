# 译文成书排版规则

Operator 开始成书排版前必须完整阅读本文档。

译文中的标点和源样式记号依 [`PUNCTUATION.md`](../translation/PUNCTUATION.md)。

# 一、排版架构

## 1. 分层

成书排版分为四层：

```text
Markdown 源记号
        ↓
排版语义
        ↓
LaTeX 语义命令
        ↓
template / 作品 .tex / 作品成书配置
```

Markdown 记录底本形态；成书阶段根据结构和功能确定排版语义，再由作品级排版实现决定最终视觉效果。

## 2. 判断原则

1. 先判断结构和功能，再判断字面形态。
2. 同一文字在不同结构位置可以使用不同排版语义。
3. 语义待定时，沿用底本原有的强调性质。
4. 同一结构在同一作品中保持一致。
5. 保持正确的译文 Markdown 内容与结构，排版调整落实在对应排版层。

## 3. 底本版式与中文适配

中文译本内页以**底本版式系统**为作品级设计依据。

优先继承：

- 开本；
- 版心位置和比例；
- 天头、地脚、内外边距关系；
- 页眉和页码位置；
- 标题与目录层级；
- 正文、注释、附录、索引等部分的版式关系；
- 图片、图题和正文的位置关系；
- 稳定的留白和视觉节奏。

可以根据中文排印调整：

- 中文字体；
- 行距；
- 首行缩进和悬挂缩进；
- 中文标点禁则；
- 中西文混排；
- 长标题换行；
- 注号形态；
- 字间距和段落间距。

中文版按中文排印需要分页。需要保留底本分页信息时，使用原页码标记。

底本页码是底本的页码标识，译本页码是译本编排的页码标识，PDF 物理页序是文件中页面的顺序。
底本页码与译本页码的对应关系按实际分页建立。

作品级排版选择所需的页码体系与原页码处理方式，确定正文互引、目录、索引、原页码标记及
PDF 页码标签的定位依据，保持不同定位方式之间的关系清楚、一致。

## 4. 文件职责

### 通用 template

提供：

- LaTeX 语义命令；
- 字体路由；
- 通用排版能力；
- 通用默认实现。

### 作品 `.tex` / 作品成书配置

负责该书的具体排版，包括：

- 作品特有结构；
- 章节装配；
- 标题与目录关系；
- 公文结构；
- 图片组织；
- 底本版式还原；
- 作品特有参数和中文适配。

作品 `.tex` 可以手工维护。通用规则进入转换器或 template；作品特有规则保留在作品 `.tex` 或成书配置中。

### 环境与示例

排版环境由使用者提供 XeLaTeX、所用宏包、具备必要字符覆盖的字体和作品资源；字体的使用与分发权限须分别确认。

最小接口练习依 [`examples/minimal/README.md`](../examples/minimal/README.md)。正式作品须自行建立符合下述语义命令及字体关系的 template / preamble、章节装配和作品成书配置，不从示例编译成功推导正式成书完成。工具输入输出及检查范围依 [`scripts/README.md`](../scripts/README.md)。

# 二、Markdown 到排版语义

## 1. 行内样式

| Markdown | 功能 | LaTeX |
| --- | --- | --- |
| `*…*` | 正文强调 | `\bookemph{}` |
| `*…*` | 署名、著录作者、附属责任信息 | `\bookapparatus{}` |
| `**…**` | 正文强调 | `\bookstrong{}` |
| `**…**` | 章末或文末署名 | `\bookapparatus{}` |
| `**…**` | 发言人标签 | `\bookspeaker{}` |
| `**…**` | 人物志、辞典式词头 | `\bookentry{}` |

语义待定时采用默认映射：

```text
*…*   → \bookemph{…}
**…** → \bookstrong{…}
```

## 2. 结构记号

| Markdown | 排版语义 | LaTeX |
| --- | --- | --- |
| 独立 `* * *` | 结构分隔 | `\bookseparator` |
| 行首 `- ` | 条目式清单 | `\bookitem{}` |
| 行首 `> ` | 作品定义的附属材料块 | `\booknote{}` |
| 行尾 `\` | 诗行强制换行；含此记号的块整块为诗行块 | `\bookverse{}`，块内以 `\\` 断行 |
| `![…](…)` | 图片 | `\bookfigure{}` |
| `[^id]` / `[^id]:` | 脚注 | 正式脚注结构 |

`- `、`> ` 和图片的具体功能由作品结构决定。其他作品出现不同用法时，在作品级排版中定义。

## 3. 连续下划线

核对底本并确认连续下划线表示手稿横线或图形性分隔后，转换为：

```latex
\bookinlinerule
```

具体识别范围由作品级排版定义。

## 4. 图片

Markdown 图片进入：

```latex
\bookfigure{}
```

以下属性由底本版式和作品级排版决定：

- 位置与是否浮动；
- 宽度和高度；
- 对齐；
- 上下留白；
- 图题关系。

正文中的手稿图、示意图等应保持其与正文的语义位置关系。

## 5. 结构元数据

例如：

```text
<!-- text-layer: ... -->
```

转换时读取结构元数据确定排版语义，再剥离元数据标记；正文、目录、页眉和最终 PDF 输出对应的排版内容。

# 三、功能语义

## 1. 正文强调

正常句子内部、参与当前语法结构的强调文字，按正文强调处理：

```text
*…*   → \bookemph{}
**…** → \bookstrong{}
```

## 2. 署名、落款和著录

明确承担作者、责任者、文献著录等附属信息功能时使用：

```latex
\bookapparatus{}
```

判断依据是文献结构和上下文。

## 3. 发言人标签

会议记录、讨论记录、速记稿中的发言导航标签使用：

```latex
\bookspeaker{}
```

排版时保持标签与其后发言正文的起始部分同页。

## 4. 人物志和辞典式词头

人物志、人物表、辞典式条目的词头使用：

```latex
\bookentry{}
```

## 5. 公文结构

信件、通知、命令、申请、档案记录等文本可使用：

| 功能 | 命令 |
| --- | --- |
| 机关抬头、文种名 | `\bookletterhead{}` |
| 标题下说明、日期等 | `\booksubtitle{}` |
| 收信人、呈报对象 | `\bookaddressee{}` |
| 正文后的落款块 | `\booksignature{}` |

机关抬头和文种名按公文内部结构排版，目录与书眉采用作品章节层级。多行落款作为一个结构块处理。

# 四、LaTeX 语义命令

## 1. 字体型命令

| 命令 | 功能 | 汉字 | Cyrillic | Latin |
| --- | --- | --- | --- | --- |
| `\bookemph{}` | 斜体型正文强调 | 黑体 | 黑体 | Italic |
| `\bookstrong{}` | 粗体型正文强调 | 黑体 | 黑体 | Bold |
| `\bookapparatus{}` | 署名、著录等附属信息 | 楷体 | 楷体 | Italic |
| `\footnoteemph{}` | 脚注中的附属著录信息 | 楷体 | 楷体 | Italic |
| `\bookspeaker{}` | 发言人标签 | 黑体 | 黑体 | Bold |
| `\bookentry{}` | 人物志、辞典式词头 | 黑体 | 黑体 | Bold |

Cyrillic 并入 CJK 字符类，随所在语义命令的汉字字体走；Latin 单独使用对应 Roman / Italic / Bold 字面。

每一种汉字语义字体都必须覆盖所需 Cyrillic 字符。

## 2. 结构型命令

| 命令 | 功能 |
| --- | --- |
| `\bookitem{}` | 条目式清单 |
| `\booknote{}` | 随正文附属材料 |
| `\bookverse{}` | 诗行块 |
| `\bookseparator` | 独立结构分隔 |
| `\bookinlinerule` | 行内图形分隔 |
| `\bookfigure{}` | 图片 |
| `\bookletterhead{}` | 公文抬头 |
| `\booksubtitle{}` | 公文说明行 |
| `\bookaddressee{}` | 收信人、呈报对象 |
| `\booksignature{}` | 落款块 |

语义命令只表达功能。字号、字重、缩进、行距、对齐、留白、图片尺寸、分隔线长度和栏数由 template 或作品级排版实现决定。

## 3. 字体实现

中文正文强调使用黑体字面。

底本 italic：

```text
汉字      → 黑体
Cyrillic  → 黑体
Latin     → Italic
```

底本 bold / ALL CAPS：

```text
汉字      → 黑体
Cyrillic  → 黑体
Latin     → Bold
```

署名、落款和著录附属信息：

```text
汉字      → 楷体
Cyrillic  → 楷体
Latin     → Italic
```

需要黑体时指定明确字重。

正文主字体 fallback 可使用 `AutoFakeBold` 与 `AutoFakeSlant`；正式语义字体采用明确的字体字面和字重。

# 五、转换与作品 `.tex`

## 1. Markdown 与 `.tex` 的边界

Markdown 已有明确记号的内容，由转换器转换为可重复生成的语义结构，输出对应语义命令。

Markdown 没有专用记号、但可以根据作品结构可靠判断的排版语义，可以直接在作品 `.tex` 中实现。

作品 `.tex` 或成书配置负责作品特有的装配、修订和排版实现。按作品维护方式明确转换输出与
手工维护文件各自的职责和更新方式。

正确的译文 Markdown 保持原有内容与结构，排版需求在作品 `.tex` 或成书配置中实现。

修改源文本、转换规则或手工排版后，按实际依赖关系更新对应文件。重新生成时保留已确认的
手工修改，按依赖关系合并更新。

利用现有文件管理方式，保留校样 PDF 与 TeX 编译入口及所用文件版本的对应关系。

## 2. 转换器边界

转换器输出语义命令，具体字体、字号和版式参数由 template 或作品级排版实现定义。

例如正文强调输出：

```latex
\bookemph{}
```

具体视觉实现由 template / 作品级排版负责。

转换诊断分为阻断错误、警告和待人工处理事项。正常脚注续段等结构处理以提示报告。
以正文引用、注释定义、底本注码和既有裁决核对转换结果。引用缺少对应定义、注文遗漏或
显示注码与底本及裁决不一致的情形归为阻断错误，返回非零状态。
正式输出在阻断错误全部解决后写入。

正式输出通过 `-o` 写入。需要保留待处理问题的草稿时，显式指定
`--draft-output 临时目录/章节.draft.tex`。草稿使用以 `.draft.tex` 结尾的独立新文件，路径位于
脚本所在仓库的 `book/projects/`、`book/templates/` 及其路径别名以外的临时目录；处理外部工程时，
草稿同样放在独立临时目录。草稿保留待处理问题并返回非零状态；问题处理完成后，生成正式输出并执行验收。

跨单元注释、标题注及已确认底本缺陷按明确裁决在作品 `.tex` 中完整处理，保留相关正文、
注码、注文及其对应关系。

## 3. 标题与目录

正文标题与目录条目是两个排版层级。

正文标题内部样式可以保留；目录使用纯标题文本，再由目录自身样式排版。

## 4. 标点

标点内容依 `PUNCTUATION.md`。成书阶段保持已经确定的中文标点、西文著录标点、外文原词内部空格、破折号 `——` 和连接号 `—`。

## 5. 分块错误

成书时发现分块或结构记号错误，返回对应源层修正，再同步更新作品 `.tex`。

涉及 block 合并时：

- 保留该组第一个 block id；
- 删除被吸收的 block id；
- 其余 block id 沿用原编号。

修正后保持底本 Markdown 与译文 Markdown 的 block-id 序列一致。

# 六、作品版式建立

每一本书在确定最终版式前，先检查底本代表页，覆盖正文、目录、标题、注释、特殊文献结构、图片、索引和附录等主要版式类型。

在现有作品配置或排版记录中至少记录：

```text
开本
版心
页边距
正文尺寸
行距
首行缩进
页眉
页码定位依据与原页码处理方式
标题层级
目录
脚注 / 注释（注号、注体、缩进、分隔线、注区间距及定位方式）
列表
图片
索引
作品特有结构
字体来源或位置
字体准备方式
TeX 编译入口
```

底本参数能够直接保留的直接采用。因中文排印需要调整时，记录底本值和中文值。

# 七、校验

## 1. 结构与源码

确认：

- 实际使用的 Markdown 结构和样式记号均已落地；
- Markdown / HTML 记号均转换为预期排版语义，结构元数据得到正确处理；
- 脚注、图片和结构元数据处理正确。

## 2. 字体

从最终 PDF 核对：

- 汉字字体正确；
- Cyrillic 随对应汉字字体；
- Latin 字面正确；
- 同一语义全书一致；
- mixed-script 对象各侧样式一致。

## 3. 编译

检查：

- missing glyph；
- Overfull；
- 明显异常的 Underfull。

异常必须定位到具体结构或版式原因。

转换、编译、结构核对、字体核对和版面校样分别完成，共同作为排版验收依据。

## 4. 版面校样

抽查各类代表性页面，重点检查：

- 正文和长标题；
- 目录；
- speaker / entry / apparatus / note / item；
- separator / inline rule / figure；
- 脚注（密集注释、跨页续注及章末注释）；
- 章首章末；
- 页眉页码；
- 索引。

核对正文、引文、注文和附属材料的实际字号、基线间距、缩进、中文标点及中西文间距。

重点处理标题、标签、词头、图片与正文之间的分页关系，以及异常留白、脚注拥挤和版心溢出。
脚注核对注号、注文、跨页续接关系及注区版面。

调整字体、字号、行距、版心或其他影响分页的参数后，复核受影响的标题分行、标题与正文
起始部分同页关系、图题关系及局部留白。复核范围与实际改动及其影响相适应。

版心以多数正文行形成的稳定边界判断，悬挂标点按标点排印规则单独核对。

## 5. PDF 交付检查

按作品适用的项目检查：

- 文档标题、作者等 PDF 文档属性与作品信息一致；
- PDF 书签层级与正文结构一致；
- 页码标签与作品确定的页码定位方式一致；
- 内部链接及其他实际使用的链接指向正确位置。

# 八、问题分流

| 问题 | 处理位置 |
| --- | --- |
| Markdown → LaTeX 映射错误 | 转换器 |
| LaTeX 语义命令实现错误 | template / preamble |
| 项目通用排版规则缺失 | 本文件 |
| 某作品特有版式需求 | 作品 `.tex` / 成书配置 |
| 译文内容或译文体例错误 | `review-notes.json` |
| Markdown 结构记号使用错误 | `review-notes.json` |
| glossary 问题 | `glossary/` |
| 原文、OCR、数字化问题 | `source-issues.json` |
| 底本换行造成错误分块 | `source-issues.json` |

# 九、完成条件

成书排版完成时确认：

- 已完成底本版式测量并建立作品级排版参数；
- 页码定位关系明确；
- 中文适配项能够追溯到底本；
- Markdown 保持已确定的文字、结构与源样式记号；
- 所有实际使用的结构和样式均已正确落地；
- LaTeX 语义命令与最终字体一致；
- 图片、目录、公文、索引等作品结构排版正确；
- PDF 所需字形完整，源码记号转换完整；
- 正文与各类结构位于预期版心内，分页与留白符合设定版式；
- 脚注及受影响的分页已完成相应校样；
- 最终 PDF 交付信息已核对；
- 校样与最终文件可追溯到对应编译入口及文件版本；
- 所有发现的问题均进入正确处理层。

满足以上条件后，成书排版阶段完成。

翻译最终校阅与发布按 Owner 明确指定的范围、阶段、完成条件和授权执行。
